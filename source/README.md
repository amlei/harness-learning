# Hermes Agent 实现剖析

> 本部分是源码学习笔记。它不是使用手册，而是反过来追问"这套系统是如何被造出来的"——
> 通过拆解 Hermes Agent 的实现机制与设计思想，把"看起来会用的能力"变成"理解原理的知识"。
>
> 全书以第三人称撰写，按功能领域分部、分章。复杂的关系与架构用 Mermaid 图呈现，
> 简单的流程与对照用 ASCII。

---
